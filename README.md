# 装修公司五Agent协作系统 — 使用说明

> 版本：v1.2  
> 日期：2026-05-12  
> 适用场景：装修公司项目管理 + AI Agent 协作 + 案例库 + 手绘草图  
> 文件位置：`decoration-agents/` 目录

---

## 一、系统简介

本系统参照「驷马五Agent协作系统」架构，为装修公司量身定制，将装修业务流程拆解为五个专业化Agent角色，形成标准化协作流水线：

```
司图（市场情报）→ 迪哥（预算分析）→ 娜娜（设计创作）→ 雷虎（合规审核）→ 小蔓（项目管家）
```

每个Agent有独立的温度参数、职责边界和输出模板，可独立开关、单独配置。

## 三、五个Agent详解

### 3.1 司图（Scout）— 市场情报Agent

| 属性 | 值 |
|------|-----|
| 温度 | 0.3（偏保守，信息准确优先） |
| 是否阻塞 | 否 |
| 对应岗位 | 市场人员、获客专员 |

**核心职责：**
- 监控本地新交付楼盘（政府公示、房产论坛）
- 抓取竞品装修公司促销活动、报价区间
- 搜集业主在小红书/抖音的装修痛点和需求
- 输出：每周线索清单 + 竞品动态简报 + 客户痛点词典

**使用方式：**  
在Web UI的「协作流水线」页面点击"运行完整流水线"，司图会第一个执行，输出线索情报供下一环使用。

---

### 3.2 迪哥（Digit）— 预算分析Agent

| 属性 | 值 |
|------|-----|
| 温度 | 0.3（计算准确优先） |
| 是否阻塞 | 否 |
| 对应岗位 | 预算员、造价员、量房师 |

**核心职责：**
- 解析量房数据（面积、户型、层高、采光方向、特殊结构）
- 计算主材/辅材用量（瓷砖×1.1、地板×1.05、涂料×2.5÷涂布率）
- 生成详细报价单（基础工程 + 主材 + 定制类 + 费用汇总）
- 成本与毛利分析，预警低毛利项目
- 输出：详细报价单 + 成本分析表

**报价单模板位置：** `templates/quote_template.md`

---

### 3.3 娜娜（Nova）— 设计创作Agent

| 属性 | 值 |
|------|-----|
| 温度 | 0.7（创意发散，文案生动） |
| 是否阻塞 | 否 |
| 对应岗位 | 设计师、文案策划 |

**核心职责：**
- 将设计师的平面图/效果图转化为客户能看懂的文字说明
- 为效果图、完工照生成小红书/抖音营销文案
- 包装典型案例（客户痛点 → 解决方案 → 效果展示）
- **【v1.2新增】** 根据客户需求从案例库推荐匹配案例（智能匹配风格/户型/面积）
- **【v1.2新增】** 生成手绘风格户型草图（Canvas模拟手绘，支持多种户型和风格）
- 输出：设计方案说明书（客户版）+ 营销文案 + 案例推荐 + 手绘草图

**设计说明书模板：** `templates/design_brief_template.md`  
**内置风格关键词库：** 现代简约、北欧、新中式、工业风、轻奢、日式  
**案例库位置：** `data/cases.json`（10个典型案例，可扩展）

---

### 3.4 雷虎（Lex）— 合规审核Agent ⚠️ 阻塞环节

| 属性 | 值 |
|------|-----|
| 温度 | 0.1（极度保守，风险优先） |
| 是否阻塞 | **是**（审核不通过则流程终止） |
| 对应岗位 | 法务、审核专员、公司负责人 |

**核心职责：**
- 审核合同条款（付款节点、违约责任、保修条款、增项条款）
- 审核报价单（模糊项、漏项、材料品牌明确性）
- 预警：报价低于成本线、条款违反消保法
- 输出：审核意见（通过/驳回+原因）— 阻塞流程

**合规标准（内置）：**
- 付款节点：开工≤30%、中期≤50%、竣工≥20%
- 保修期：基础工程≥2年、防水工程≥5年
- 增项：需客户书面确认，不超过总价10%

**审核报告模板：** `templates/contract_check_template.md`

> ⚠️ **重要**：雷虎是阻塞环节，审核驳回后流水线终止，必须修改后重新审核。

---

### 3.5 小蔓（Memo）— 项目管家Agent

| 属性 | 值 |
|------|-----|
| 温度 | 0.2（稳妥记录，不遗漏） |
| 是否阻塞 | 否 |
| 对应岗位 | 项目经理、客服、工程监理 |

**核心职责：**
- 建立每个客户的完整项目档案
- 追踪施工节点（开工→水电→泥木→油漆→竣工）
- 记录每次客户沟通要点
- 节点提醒（验收前1天、付款前2天、保修回访）
- 输出：项目档案 + 项目周报 + 待办清单

**项目周报模板：** `templates/project_report_template.md`  
**施工节点工期参考（内置）：** 拆旧3-7天 + 水电7-10天 + 瓦工10-15天 + 木工5-10天 + 油漆10-15天 + 安装3-5天 = **合计38-62天**

## 四、Web UI 使用指南

### 4.1 启动方式

**方式一：直接打开（推荐）**
1. 将 `decoration-agents` 文件夹复制到U盘或任意目录
2. 双击 `webui/index.html`
3. 用浏览器（Chrome/Edge）打开即可使用

**方式二：U盘便携使用**
1. 将整个 `decoration-agents` 文件夹复制到U盘根目录
2. 任意电脑插入U盘，找到 `decoration-agents/webui/index.html`
3. 双击打开，立即使用（无需安装任何软件）

> ✅ 数据自动保存在浏览器本地存储（localStorage），下次打开自动恢复。

---

### 4.2 各页面功能

### 4.3 配置步骤（首次使用）

1. 打开 `webui/index.html`
2. 点击顶部导航「⚙️ 系统配置」
3. 填写公司信息：
   - 公司名称：如「XX装饰设计有限公司」
   - 公司地址：详细地址
   - 联系电话：客服电话

## 七、常见问题（FAQ）

**Q1：Web UI需要联网吗？**  
A：不需要。所有功能在本地运行，数据存在浏览器本地，U盘里打开即用。

**Q2：如何把配置迁移到另一台电脑？**  
A：直接复制整个 `decoration-agents` 文件夹到另一台电脑，双击 `index.html` 即可。配置已保存在 `localStorage`，也可手动编辑 `config.json` 作为默认配置。

**Q3：雷虎审核不通过怎么办？**  
A：根据审核报告中的「修改建议」修改合同或报价单，然后重新提交审核。雷虎是阻塞环节，不通过不能进入下一环。

**Q4：五个Agent可以只用其中几个吗？**  
A：可以。在「系统配置」页面，点击每个Agent卡片右侧的开关即可禁用。流水线运行时会自动跳过已禁用的Agent。

**Q5：模板文件可以修改吗？**  
A：可以，而且推荐修改。根据实际业务调整模板内容，使其更符合公司习惯。修改后记得另存为新文件，不要覆盖原模板。

**Q6：如何备份项目数据？**  
A：项目数据存在浏览器 `localStorage` 中。如需备份，可：
1. 在浏览器开发者工具（F12）的 `Application > Local Storage` 中导出
2. 或手动将项目信息填写到 `templates/project_report_template.md` 中归档

## 八、技术说明

- **前端**：纯HTML + CSS + JavaScript，无任何后端依赖
- **数据存储**：浏览器 `localStorage`（同域名/同文件路径下持久化）

- **浏览器兼容**：推荐 Chrome / Edge / Firefox 新版

## 十、案例库使用指南（v1.2 新增）

### 10.1 案例库页面功能

在Web UI顶部导航点击「📁 案例库」，进入案例库页面：

- **案例卡片**：展示所有成功案例，包含户型、面积、风格、造价、客户评分
- **缩略草图**：每个案例卡片顶部有一张手绘风格户型缩略图（Canvas自动生成）
- **筛选按钮**：点击「全部 / 现代简约 / 北欧 / 轻奢 / 新中式」快速筛选
- **搜索框**：输入关键词（风格、户型、楼盘、标签）实时搜索

### 10.2 案例推荐算法

当客户在「💬 客户对话」中输入需求后，**娜娜(Nova)的回复会自动推荐2个最匹配的成功案例**。

推荐逻辑（按得分排序，取前2名）：
1. **风格匹配**（权重×5）：客户需求包含某风格关键词，且案例风格一致
2. **户型匹配**（权重×4）：客户提到"三室"/"两室"等，与案例户型匹配
3. **面积匹配**（权重×3）：客户输入面积（如"110㎡"），与案例面积相差<20㎡则加分
4. **预算匹配**（权重×3）：客户输入预算（如"20万"），与案例总造价相差<30%则加分
5. **标签匹配**（权重×2）：客户输入包含案例标签词（如"刚需"、"收纳"）

### 10.3 扩展案例库

编辑 `data/cases.json`，在 `cases` 数组中添加新案例：

```json
{
  "id": "C011",
  "title": "工业风·两室一厅",
  "style": "工业风",
  "layout": "两室一厅一卫",
  "area": 88,
  "budget": 145000,
  "budget_per_sqm": 1648,
  "duration": 68,
  "location": "西安·高新区",
  "completion_date": "2026-04",
  "tags": ["工业风", "两室一厅", "个性"],
  "highlights": ["裸露砖墙", "铁艺楼梯"],
  "materials": "水泥自流平、红砖、铁艺",
  "satisfaction": 5
}
```

> 💡 **提示**：`id` 不能重复，`tags` 用于搜索匹配，`highlights` 在案例详情中展示。

## 十一、手绘草图使用指南（v1.2 新增）

### 11.1 在对话中获取草图

客户在「💬 客户对话」中输入需求后，**娜娜(Nova)的回复末尾会包含一个「🎨 生成手绘草图」链接**：

1. 点击该链接 → 弹出「娜娜 · 手绘草图」弹窗
2. 选择**户型**（一室一厅 / 两室一厅 / 三室两厅 / 三室一厅 / 四室两厅）
3. 选择**风格**（现代简约 / 北欧 / 新中式 / 轻奢）
4. 草图自动生成（Canvas手绘风格，带抖动线条和网格背景）
5. 点击「下载草图」保存为PNG图片

### 11.2 从案例详情查看草图

在「📁 案例库」中点击任意案例卡片 → 弹窗展示案例详情 + **手绘草图**（自动根据该案例的户型生成）

### 11.3 手绘草图的技术说明

- 使用 HTML5 Canvas API 生成，纯前端，无需后端
- **手绘效果**：线条带随机抖动（模拟手绘误差），外墙用多段短线模拟手绘质感
- **网格背景**：模拟方格草稿纸
- **标注文字**：户型功能分区（客厅、卧室、厨卫等）

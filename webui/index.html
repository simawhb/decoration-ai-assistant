使用指南

1

描述您的需求

进入「咨询对话」页面，输入户型、面积、预算、风格偏好等信息，也可以直接点击预设问题快速开始。

2

AI专家自动响应

系统会根据您的问题智能匹配对应的专家回答：
🔍 司徒（市场专员）— 竞品行情、楼盘动态
📐 迪哥（预算造价师）— 报价估算、材料用量
🎨 娜娜（首席设计师）— 风格方案、空间布局
🛡️ 雷虎（法务主管）— 合同审核、增项风险
📋 小蔓（项目经理）— 工期安排、进度跟踪

3

查看案例与草图

娜娜会根据您的需求推荐匹配案例，并生成手绘风格草图，支持现代简约、北欧、新中式、轻奢四种风格。

4

配置AI服务

进入「AI 设置」页面，可免费注册 Groq、硅基流动等 AI 服务获取 API Key，获得更智能的回答。也可使用本地 Ollama 离线模式。

五Agent协作流程

我们采用五位AI专家协同工作模式，从市场分析到项目交付，全流程专业覆盖。

流程说明

🔍 司徒（市场专员） — 分析市场行情、竞品报价、楼盘动态，为您提供最新市场情报。
📐 迪哥（预算造价师） — 根据户型面积、装修档次精准估算报价，计算材料用量。
🎨 娜娜（首席设计师） — 根据需求给出设计方案、风格搭配、空间规划，生成手绘草图。
🛡️ 雷虎（法务主管） — 审核合同条款、报价合规性，预警增项风险，保护您的权益。
📋 小蔓（项目经理） — 项目进度规划、工期安排、节点提醒，确保按时保质交付。
